# PlagX

An Explainable Multilingual Plagiarism Detection System.

## Features

- Exact plagiarism detection
- Paraphrase detection
- English-Hindi cross-lingual detection
- Public web source discovery
- Local document comparison
- Source attribution
- Highlighted matching passages
- Downloadable PDF reports

## Technology Stack

- React
- Tailwind CSS
- Python
- FastAPI
- SQLite
- Scikit-learn
- Sentence Transformers
